Centre Insertion Professionnelle Learning is a web-based educational management platform developed with Laravel for the Women's Professional Insertion Center in Benslimane. The platform streamlines the administration and distribution of learning materials, enabling efficient management of PDF documents and video modules.

Core Features

Resource Management: Upload, update, and categorize PDF course materials and instructional videos.

Media Streaming & Access: Structured video and document viewer for beneficiaries to access training content.

Content Administration: Dedicated management dashboard for uploading and organizing educational assets.

Tech Stack

Backend: Laravel (PHP)

Database: MySQL

Frontend: Blade, HTML5, CSS3
